##  Project Overview

This project focuses on detecting fraudulent transactions using classification models. It walks through comprehensive **data preprocessing**, including cleaning, transformation, reduction, normalization, and discretization. The dataset used contains realistic, synthetic financial transaction records.

The core objective was to build a predictive model to classify whether a transaction is **fraudulent (1)** or **not fraudulent (0)** based on 20+ transaction and user features.
